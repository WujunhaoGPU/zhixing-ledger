# 知行簿独立插件

## 产品定位

知行簿是一个独立 Chrome / Edge 插件，用来把 AI 学习对话结算成可见、可复习、可导出的成长记录。ChatGPT 继续负责自然对话、解释和图片生成；插件负责开始复述、结算预览、用户确认、本地台账、技能卡与无边记提示词。

它不替代续谈，也不替代无边记。

## 核心闭环

`收录学习资料 -> L0 知识卡 -> 技能树发现下一项 -> ChatGPT 主动学习 -> 证据推动 L1-L4 -> FSRS 复习 -> 无边记图片提示词`

原则：

- 先复述再解释，一次只练一个知识点。
- 压缩重复，不压缩推理、反馈和学习过程证据。
- 输入必须先解析和预览，不能无声写入空记录。
- 本地规则解析优先；陌生格式才可选择调用 DeepSeek。
- DeepSeek 输出仍是不可信输入，必须再次经过同一套标准化与校验。
- API Key 只保存在浏览器本地扩展存储，不进入导出文件。
- 卡片内容丰富程度与用户能力等级分开；AI 解释只能增加内容，不能替用户升级。
- 技能树只负责显示知识关系和推荐下一项，不替代 FSRS，也不直接修改 L0-L4。

## M0-M3 范围

### M0：阻断空导入

- 兼容当前真实结算字段：`topic`、`score`、`status`、`newCard`、`exposedProblem`、`nextReview`、`nextReviewPrompt`。
- `newCard.current_level = "L3: ..."` 或顶层 `score = 3` 都能正确映射等级。
- `{}`、无有效字段文本和空技能卡不能写入台账。
- 旧版蛇形字段、旧版台账字段和紧凑技能卡格式继续兼容。

### M1：Canonical V2 与确认式导入

- 统一规范版本：`schemaVersion: 2`。
- 解析后展示格式、置信度、识别数量、警告和字段预览。
- 只有点击“确认写入”才更新本地状态。
- 保存上一次导入前快照，支持一次撤销。
- 原始输入格式不直接决定存储结构；V1/V2 输入经过兼容层适配到当前 Canonical V3。

### M2：DeepSeek BYOK 智能解析

- 设置页由用户自行保存 API Key、选择模型、测试连接和启停。
- 默认先使用本地解析器；格式未知或字段完整度低时才调用 DeepSeek。
- 支持用户显式点击“使用 DeepSeek 重解析”。
- DeepSeek 只抽取原文中明确出现的内容，不允许补造学习记录。
- 后台请求具有 45 秒超时和最多一次可恢复错误重试。
- 失败时返回安全错误，不回显 API Key。

### M3：页面工作流重构

- **今日**：今日摘要、捕获或粘贴、解析预览、确认写入、撤销、时间线；手动追加收进高级区域。
- **卡组**：保留 B 方案的周历、训练主卡、等级筛选与真实技能卡列表；演示卡不计入统计和地图。
- **探索**：显示知识技能树、可学习节点、锁定前置、点亮进度和当前学习节点；完整图谱在独立宽屏页打开。
- **制图**：选择真实技能卡、勾选内容模块、选择手写白板/课堂板书/知识卡片风格、生成并保存提示词。
- **设置**：DeepSeek 配置、三套固定提示词、数据统计、Markdown/JSON 导出、备份导入和清空数据。

### M4-M7：知识生命周期

- **M4 数据模型**：Schema V3 为卡片增加 `sources` 与 `levelEvents`；V2 卡片迁移时用 `legacy` 证据保留原等级。
- **M5 知识收录**：新增“收录当前学习”提示词和入口；书籍、文章、AI 对话可以直接生成内容丰富的 L0 卡。
- **M6 分级训练**：L0-L4 分别对应理解确认、独立复述、现实应用、迁移推演和巩固复盘。
- **M7 证据可视化**：卡片详情拆成知识内容、成长证据和来源；卡组同时显示模块数、来源数和下一步行动。
- **M8 复习调度**：使用本地 FSRS 根据实际提取难度安排日期；每日队列最多 3 张，并优先到期旧卡、最多加入 1 张 L0 新卡。
- **M9 ChatGPT 分级复习**：插件根据 L0-L4 生成单卡训练提示词；ChatGPT 负责灵活出题、追问、单点反馈、表达改写和二次复述。
- **M10 结构化结算闭环**：插件捕获或接收 ChatGPT 最终 `knowledge_ledger_update`，展示评分、两次复述、反馈、进步证据和图片提示词；用户确认后才写入并更新 FSRS。
- **M11 首次启动指南**：新安装自动展示四屏简介，可跳过、前后切换，并能在设置页重新打开。已读状态单独保存，不进入学习备份。
- **M12 探索技能树**：内置人工校准的 21 节点“芒格多元思维模型”标准树；卡片按名称、别名和显式关联映射到节点，状态由卡片证据和前置关系实时推导。
- **M13 节点学习闭环**：从可学习节点复制专属 ChatGPT 教练提示词，完成诊断、讲解、第一次复述、单点反馈、二次复述和 V3 结算；导入同名卡后自动点亮对应节点。
- **M14 自适应小树**：选择 1-5 张真实能力卡，由 DeepSeek 提出 5-12 节点的有向无环小树；新增节点初始为待确认候选，用户确认纳入也不会改变能力等级。

## 探索技能树 V1

技能树使用独立的 `ability-tree/v1` 结构，存放在现有本地状态的 `knowledgeTrees` 中；学习中的树和节点存放在 `exploration`。结算协议继续使用 Canonical V3，不为技能树另建能力等级来源。

节点状态：

- **可学习**：没有未满足的硬前置，且尚无关联能力卡。
- **锁定**：至少一个 `requires` 前置尚未达到要求；`recommended` 只影响顺序，不锁定。
- **L0 已收录**：已有关联卡，但只有收录证据。
- **L1-L2 学习中**：已形成理解或独立复述证据。
- **L3-L4 已应用**：已有真实应用或跨领域迁移证据。
- **待确认**：DeepSeek 提出的新节点，尚未由用户确认纳入知识范围。
- **待复习**：FSRS 到期覆盖标记，可以与上述任一已点亮状态同时存在。

第一版技能树来源分两类：

1. 标准树：围绕一本书或天然知识体系人工校准，例如芒格多元思维模型。
2. 生成树：用户选择零散能力卡并声明“共同主题、同一来源或共同目标”，DeepSeek 只提出附近知识和关系，用户预览后保存。

技能树不是目录，也不是强制线性课程。`requires` 只表达真正阻塞理解的前置关系；普通相关性使用 `recommended`。一张卡可以通过名称、别名或 `linkedCardIds` 映射到节点，节点本身不保存第二套能力等级。

`contentBlocks` 用于承接未来可能新增的方法、边界、证据、反例等内容，避免因为 JSON 字段变化再次丢失信息。长对话结算时不应只保留核心结论；在原文有依据时，还应保留为什么重要、核心问题、推理链、关键区分、两次复述、教练反馈、进步证据和代表性用户原话。

能力卡使用“结论层 + 上下文层 + 证据层 + 来源层”：

- 结论层：`oneLine`、`threeSentence`、`myCase`，用于快速浏览和面试调用。
- 上下文层：`contentBlocks`，用于保留推理、纠错、证据和后续复习材料。
- 证据层：`levelEvents`，只记录用户自己的理解、复述、应用和迁移。
- 来源层：`sources`，记录对话、书籍、文章和手动材料。
- 去掉寒暄与重复，但不以“更短”为目标。原文信息充分时，一张卡建议保留 6-12 个有实质内容的上下文模块。
- 用户从单张卡开始复述时，插件会把该卡已保存的上下文重新加入开始提示词；卡组总览只展示模块名称，避免一次提示词过长。

## 评分与等级

复述评分：

- 0：说不出来
- 1：只能说关键词
- 2：能用三句话讲清楚
- 3：能举例并应用到现实问题

技能等级：

- L0：已收录，尚无用户输出证据
- L1：能用一句自己的话解释
- L2：能完成独立复述
- L3：能在真实场景中应用
- L4：能迁移到陌生问题并进行推演

评分描述的是本轮复述，等级由累计成长证据推导；卡片保存了多少内容也不能作为升级依据。

L0-L4 不提供手动选择器。等级只能由带有用户原话的 `understanding`、`recall`、`application`、`transfer` 证据推导；旧版本产生的 `manual_override` 记录在加载时清除，不能继续影响等级。

## 复习调度与训练

复习页采用三层职责分离：

- **FSRS 决定何时复习**：每张卡保存 `reviewSchedule` 和 `reviewLogs`，根据“忘记 / 困难 / 正常 / 轻松”更新下次到期时间。
- **L0-L4 决定练什么**：L0 做理解确认，L1 做独立复述，L2 做现实应用，L3 做迁移挑战，L4 做边界与反例巩固。
- **ChatGPT 决定如何训练**：插件把当前技能卡、历史证据、等级目标和结算协议组合成提示词；ChatGPT 可以根据回答动态缩小问题、比较模型和设计陌生场景。
- **插件负责可信落地**：只解析最终结构化结算，先展示预览，再由用户确认写入；ChatGPT 输出不能直接修改本地技能卡。

ChatGPT 的 0–3 分描述本轮能力证据；“忘记 / 困难 / 正常 / 轻松”描述提取难度并影响 FSRS 间隔。两者在预览页分开显示，用户可以确认提取难度。只有结构化结算中的用户原话形成对应理解、复述、应用或迁移证据后，L0-L4 才会变化。

每日队列遵守以下规则：

1. 只展示今天到期或已经逾期的卡，不用连续打卡诱导提前刷卡。
2. 最多安排 3 张，优先复习旧卡；如果有 L0 新卡，每天最多加入 1 张。
3. 每张任务明确显示入选原因、本轮题型和预计时长。
4. 进入任务后复制完整训练提示词到 ChatGPT；训练结束后捕获最新助手回复，或手动粘贴结算。
5. 预览页展示评分、等级变化、第一次复述、关键反馈、第二次复述、进步证据、全部上下文模块和图片提示词。
6. 用户确认后才更新技能卡和 FSRS；卡片详情继续保留复习记录、两次回答、关键缺口、成长证据和关联台账。

DeepSeek 不参与卡组复习。它只用于陌生结算格式转换和地图结构自适应；正常复习由当前 ChatGPT 对话完成，插件不调用私有 ChatGPT API，也不自动发送消息。

## 固定使用流程

1. 学习书籍、文章或 AI 对话时，复制“收录当前学习”提示词。
2. 捕获回复并确认写入，生成内容丰富但等级保守的 L0 卡。
3. 在“今日复习”查看系统根据到期时间选出的任务，以及每张卡为什么需要复习。
4. 复制当前卡的完整训练提示词，在 ChatGPT 中完成出题、第一次复述、反馈和二次复述。
5. 捕获或粘贴 ChatGPT 最后的 `knowledge_ledger_update`，检查插件生成的结算预览。
6. 单独确认 FSRS 提取难度，再确认写入；插件保存证据、重新推导等级并安排日期。
7. 没有到期复习、想继续学习时进入“探索”，从满足前置的推荐节点中选择下一项。
8. 复制节点学习提示词到 ChatGPT，完成小闭环后回到“今日”导入结算；同名能力卡会点亮节点。
9. 零散知识需要形成路线时，从“探索”选择 1-5 张卡建立小树，检查 AI 建议节点后再保存。
10. 需要制作无边记知识图时进入“制图”，选择卡片内容和视觉风格后生成提示词。
11. 所有导入都先预览再确认；有误时清除预览或使用撤销。

制图提示词采用混合生成：

- 本地规则只负责提供真实卡片内容、用户选择的模块、视觉风格和禁止项。
- 启用 DeepSeek 后，由模型判断当前知识更适合流程图、因果图、对照图、边界图、结构图还是案例图。
- 不固定使用三栏、能力圈等级图、复述闭环或每日台账锚点；主示意图必须解释当前知识本身。
- DeepSeek 不可用时自动回退到本地内容驱动模板，地图功能仍可继续使用。
- 没有被选择或没有真实内容的模块不得补写，熟练度和台账状态默认不进入图片。
- 卡组不提供图片提示词入口；卡组负责复习、证据和内容查看，制图是唯一的图片提示词生成入口。

## 边界

- 原手动流程不调用私有 ChatGPT API；用户已明确允许新增实验性 Codex OAuth 兼容接入，见 [知行簿 Codex 训练闭环](zhixing-codex-training.md)。不自动控制 ChatGPT 网页多轮对话。
- 不自动抓取完整聊天历史，保留手动粘贴回退。
- 不把 DeepSeek 结果直接写库。
- 不做账号系统、云同步或移动端。
- 不直接生成图片，只生成可复制给 ChatGPT 图片生成的提示词。
