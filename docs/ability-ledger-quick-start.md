# 知行簿快速使用手册

知行簿是一个配合 ChatGPT 使用的本地 Chrome / Edge 插件。ChatGPT 负责对话、出题和反馈；插件负责收录学习内容、安排复习、保存成长证据和备份数据。

## 安装

1. 先解压收到的 `ability-ledger-v版本号.zip`。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”。
4. 选择解压后包含 `manifest.json` 的 `ability-ledger-v版本号` 文件夹，然后打开 ChatGPT 和插件侧边栏。

如果使用开发者源码，则直接选择 `src/ability-ledger-extension`。

首次启动时会自动出现四屏新手指南。之后可以在“设置 -> 使用帮助”里重新打开。

## 完整使用循环

1. **收录**：学完一段对话、一章书或一篇文章后，复制“收录当前学习”提示词给 ChatGPT。
2. **入账**：在“今日”捕获或粘贴 ChatGPT 返回的 `knowledge_ledger_update`，检查预览后确认写入。
3. **复习**：在“卡组”打开今天到期的卡，复制完整训练提示词到 ChatGPT，完成第一次回答、单点反馈和第二次回答。
4. **结算**：把 ChatGPT 最后生成的结算导回插件，确认后记录本次评分、用户原话和下次复习日期。
5. **探索**：没有到期复习但想继续学习时，进入“探索”查看技能树推荐，选择一个可学习节点。
6. **学习新节点**：复制节点提示词到 ChatGPT，完成诊断、讲解、两次复述和结算，再回到“今日”导入。
7. **可视化**：需要时进入“制图”，选择卡片和内容模块，生成提示词并交给 ChatGPT 生成无边记知识图。
8. **备份**：定期在“设置”导出 JSON。更换浏览器或分享数据时，使用“导入 JSON 备份”恢复。

## 四个模块

| 模块 | 用途 |
|---|---|
| 今日 | 收录 ChatGPT 结算、预览后入账、查看每日台账。 |
| 卡组 | 查看当日复习任务、把训练交给 ChatGPT，记录 L0-L4 成长证据。 |
| 探索 | 用技能树显示已点亮、可学习、锁定和待复习知识，并推荐下一项。 |
| 制图 | 将某张能力卡转成适合 Apple 无边记的图片提示词。 |
| 设置 | 管理 DeepSeek 可选智能解析、固定提示词、新手指南和数据备份。 |

## 技能树怎么用

1. 打开“探索”，先看“现在适合学习”，不要从锁定节点开始。
2. 点击“学习”会复制一个只围绕当前节点的 ChatGPT 提示词，并记录“正在学习”。
3. 在 ChatGPT 中先回答诊断题，再完成讲解、第一次复述、单点反馈和第二次复述。
4. 把最后的 `knowledge_ledger_update` 导回“今日”；能力卡证据满足条件后，树上节点会自动点亮。
5. 想看完整关系时点击“打开完整技能树”。实线表示硬前置，虚线表示建议顺序；FSRS 到期会额外显示待复习标记。
6. 零散卡片可以点击“从技能卡建立学习地图”，选择 1-5 张卡和组织依据，再让 DeepSeek 生成预览。

DeepSeek 新增的节点只是候选。初始显示为“待确认”；确认纳入只表示这个知识值得放进地图，不会把它升级到 L1-L4。

## L0-L4 如何变化

- L0：已收录，还没有用户输出证据。
- L1：能用自己的一句话解释。
- L2：能独立完成复述。
- L3：能在真实场景中应用。
- L4：能迁移到陌生问题并进行推演。

等级不能手动调整。只有结构化结算中保存的用户原话，才能成为升级证据。

## 数据边界

- 台账、卡片、复习记录和 DeepSeek API Key 默认保存在当前浏览器本地。
- DeepSeek 是可选功能；不配置也可以完成主要学习循环。
- 插件不会替你自动操作多轮 ChatGPT 对话。关键结算都需要用户预览和确认。
- 分享插件给别人时，只分享插件文件；不要把包含个人学习记录或 API Key 的浏览器数据一起分享。

## 在知行簿内直接训练（Codex）

1. 安装 Python 3.11 或更新版本，双击项目根目录的 `启动知行簿.command`，保持窗口打开。
2. 重新加载 `src/ability-ledger-extension`，在设置的“Codex 学习教练”中输入启动窗口的配对码。
3. 点击登录 Codex，在浏览器完成本人账号授权，然后回到插件刷新连接。若回调页无法打开，可展开手动完成登录，粘贴本次回调地址。
4. 选择训练模型和支持的推理强度，点击测试模型调用。已登录与目录获取成功均不等于实际调用成功。
5. 在卡组点击“在知行簿内训练”；没有卡片时展开“从新材料开始训练”，填写主题和材料，确认收录为 L0。
6. 完成第一次回答、关键反馈和第二次回答。结算会先展示原话、反馈和等级预览，再由你选择提取难度、确认写入。
7. 中断或停止后可重试；关闭侧栏后重新打开同一张卡可继续本地草稿。未确认的训练不改变复习日期。
8. JSON 和 Markdown 导出包含训练过程；设置中退出 Codex 清除本地服务凭据。服务使用独立登录文件，不读取 DeepTutor 或 Codex CLI 登录。

本功能使用实验性 Codex 兼容接口，上游变化可能导致需要更新。限流或失败不会自动切换到其他收费服务。

需要记录实际应用时，在第一次回答前切换“真实应用复盘”，填写实际做过的行动和观察结果。尚未实践时使用普通复述/情境练习；两种训练都需要你审核结算，模型建议不代表客观能力认证。
